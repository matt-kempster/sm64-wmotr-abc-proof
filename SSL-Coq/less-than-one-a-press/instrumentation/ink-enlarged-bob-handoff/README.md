# Independent enlarged-Bob handoff reconstruction

The direct Bob129 positive was found in `../ink-enlarged-bob-target/`.
This package independently reconstructs it from fresh roots twice and exports
an exact generic recipe for original-JP replay. The proposed wider earlier-frame
menu was never run and is not counted; its unused scaffolding was removed.

From the SSL project in PowerShell:

```powershell
& build/wafel-pilot/python/python.exe instrumentation/ink-enlarged-bob-handoff/validate_shadow.py
& build/wafel-pilot/python/python.exe instrumentation/ink-enlarged-bob-handoff/export_positive.py
& build/wafel-pilot/python/python.exe instrumentation/ink-enlarged-bob-handoff/diagnose_controls.py
```

`search.py` supplies the tested reconstruction helpers and isolated diagnostic
fork, despite its historical filename. It does not run a menu when invoked.
`positive-case.json` contains all initial writes (including the exact native
donor-profile transplant), later actor cuts, inputs and expected rich samples.
`stock65-closer-100-case.json` exports an informative registered-contact negative
with the unmodified native stock Bob. `positive-reconstruction.json.gz` and
`control-diagnostics.json.gz` preserve independent checks against the target
study's full selected records.

The cache screen temporarily changes action to `ACT_DISAPPEARED` and argument
to zero on an isolated saved-state fork, advances one neutral update, reads the
floor/cache and first action event, then restores the entire original state.
The action is intangible and its handler uses the already-set cache without
performing ground quarters. This diagnostic matches the two previous hooked
original-JP controls exactly and preserves their full snapshots on restore.
It is a scoped diagnostic, not a global equivalence theorem. No diagnostic
action, position, floor or cache is transferred into an actual candidate.
Actual histories retain their normal action and run through capture/arrival.

All actual Mario edits are before the first high FREEFALL update. Profile
fields come from a separately replayed native no-A donor, but copying them into
this fixture remains an explicit setup grant. No joined shell/Bob/high-Mario
delivery history is claimed. See the main note
`docs/notes/ink-enlarged-bob-handoff.md` and the profile/target companion packets.

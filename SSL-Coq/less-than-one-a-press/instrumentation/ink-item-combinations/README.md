# Stock SSL Area 1 item combinations

This finite native JP Wafel study has two explicitly separate purposes:

* `search.py` tests high **supplied airborne** starts with stock actor pairs
  and triples. No ground action is supplied in its primary 1280-recipe menu.
* `necessary.py` supplies an established high BUTT_SLIDE, then finds two/three
  actor placements for which removing any actor loses the recorded useful
  handoff. This is a conditional handoff, not an action-entry route.

The current broader verdict and stronger native-action predecessor are in
`docs/notes/ink-item-combination-verdict.md` and
`docs/notes/ink-item-native-slide-combinations.md`. This study's single-update
high-air failures do not exclude those longer histories.

Run from `SSL-Coq/less-than-one-a-press` in Windows PowerShell. Use fresh
output names; each script refuses to overwrite an existing output:

```powershell
& ./build/wafel-pilot/python/python.exe instrumentation/ink-item-combinations/search.py build/wafel-pilot/capture.bKv95w/inputs.jsonl build/NEW-item-combinations.json
& ./build/wafel-pilot/python/python.exe instrumentation/ink-item-combinations/necessary.py build/wafel-pilot/capture.bKv95w/inputs.jsonl build/NEW-item-necessity.json
& ./build/wafel-pilot/python/python.exe instrumentation/ink-high-delayed-shell/floor_null_primer.py build/wafel-pilot/capture.bKv95w/inputs.jsonl build/NEW-floor-null-primer.json
```

Both item scripts use the shared, native initialized inventory in
`instrumentation/ink-item-clone-controls/fixtures.py`. No type, radius,
height, tangibility or interaction-status field is manufactured. Conditional
non-HOLDABLE carry-clone variants supply only the helper's parent/script/stack
effects in addition to XYZ; no pickup/release/delivery history is claimed.
Native HOLDABLE Buddy, box and Bob-omb callbacks remain active. All A inputs
are clear, and write guards forbid further state writes after the initial cut.

The main menu preserves four updates per recipe and complete selected
40-update continuations (stopping at first Area 2 entry). Every positive
control has full removal ablations from the same saved prefix. A removal
omits that actor's placement/freeze, leaving it in its original native world
state; all remaining actor positions/modes and Mario fields remain identical.
Actor selection still follows native collision-list and interaction-type
ordering. Counterfactual prefixes and same-type controls distinguish actual
push/bounce contributions from mere overlap registration.

The targeted geometry search checks 378 original pair/triple recipes and 439
removal screens, retains three cases where every actor matters, then repeats
those cases and all removals at Y=67277 and 90536. The first alias misses the
required top floors; 90536 is exactly 25000 + 65536 and preserves the successes.
These are tested heights, not an all-VPU periodicity theorem.

`preserve.py` packages the final raw outputs into
`docs/notes/ink-item-combinations-receipt.json`. It includes the eight
floor-NULL primer controls and 32 fresh boundaries. Its explicit indices
deduplicate repeated complete histories while preserving every observation.
Earlier development outputs remain ignored; only the named final outputs
contribute the reported counts. No new Coq proof or original-ROM execution
is claimed by these scripts; the stronger original-ROM result has its own
separate instrumentation and receipt.

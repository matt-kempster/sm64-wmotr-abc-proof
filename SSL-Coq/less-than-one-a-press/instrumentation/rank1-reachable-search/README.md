# Rank 1: controller-produced approaches before the top window

Checked 27 September 2026. **132 finite JP controller choices; no Ink witness.**
This is instrumentation and replay evidence, not a Coq proof or exhaustive
controller search. The [plain-language report](../../docs/notes/rank1-reachable-search.md)
states the findings and remaining gameplay boundary.

## Scope and inputs

Reuse the pinned Wafel 0.8.5 / Python 3.9.13 JP adapter from
`../wafel-jp-pilot/`. `create_game` checks the unlocked DLL hash. The existing
authentic-JP baseline is generated by the pilot's default capture command.
The only writes are its accepted pre-entry level-select flag and controller
pad fields. States are saved only after a replayed prefix; every prefix sample
is compared with the existing emulator capture. No independent RNG choice,
supplied depth, pose, action, support or object state is allowed.

`search.py --batch approach` tries first polls 2549, 2555 and 2561, four paths
and six B/Z choices, each for 240 advances: 72 cases. `--batch box` tries first
polls 2540 and 2549, five box alignments, three stick strengths and two pickup
distances, each for 420 advances: 60 cases. The first 2540 prefix is before
the fourth-pillar trigger. All 132 keep A released. Held-A entry histories,
earlier producer histories, other stars/acts and all controls are not covered.

Some choices coincide. Each manifest records every policy and horizon, the
source and baseline hashes, and the lack of pruning or state merging. Output
files permit resuming an identical search; a changed search script requires
a new output directory. Each case saves the complete input prefix/suffix and
one final observation poll, its after-update snapshots and summary.

## Exact observer

`probe.c` adds optional hooks to the existing warp/pilot observer. Its runner
authenticates the retail JP ROM and existing instruction ranges and compiles
with warnings as errors. The two geometry-return sites additionally check the
preceding `find_floor` JAL instructions. No game-memory write API is added.

At each selected call, it records F12/F14/a2 coordinates and the floor-output
address; at the caller's real return it reads F0 and the returned floor. F0 is
the result, **not the old cached `floorHeight`**. The final caller's local floor
is read at stack offset 60, as in the existing authenticated observer. The
checker requires matching entry arguments, return records and output cells,
valid live-list membership, and the exact rounded four-unit/owner decision.
List membership is checked by following the live node-pool links, not by
assuming the inherited Rank-1 cache was initialized. The earlier attempts that
used that cache failed validation and are not the final evidence.

The observer records nine position words at collision entry, geometry return,
interaction entry, accepted warp return, ordinary-copy return and final
query/store return. Position write watches record the instruction, target and
old word; they are observation of CPU writes, not injected writes. First Area-2
apply entry and return are also recorded. Their `floor`/`height` fields are
unused placeholders, not a claim about Area-2 floor availability. Their real
position and platform readings show a null platform and no displacement here.

The original top slot is tracked separately from its current behavior. A live
behavior census is taken at accepted warp return. No inactive-owner rejection
is added to the platform decision. This batch finds no owned final selection;
it does not validate a nonnull retained payload or its reuse through the warp.

## Reproduce

From the SSL project directory, with the pilot's baseline available:

```powershell
& './build/wafel-pilot/python/python.exe' instrumentation/rank1-reachable-search/search.py build/wafel-pilot/capture.bKv95w/inputs.jsonl --output build/rank1-reachable-search/approach-checked
& './build/wafel-pilot/python/python.exe' instrumentation/rank1-reachable-search/search.py build/wafel-pilot/capture.bKv95w/inputs.jsonl --batch box --output build/rank1-reachable-search/box-checked
```

The exact observer uses the existing Ubuntu-24.04 emulator environment:

```sh
bash instrumentation/rank1-reachable-search/capture.sh /path/to/baserom.jp.z64
RANK1_SEARCH_FIRST=2549 RANK1_SEARCH_END=2789 bash instrumentation/rank1-reachable-search/capture.sh /path/to/baserom.jp.z64 build/rank1-reachable-search/approach-checked/2549-direct-none.inputs
RANK1_SEARCH_FIRST=2549 RANK1_SEARCH_END=2789 bash instrumentation/rank1-reachable-search/capture.sh /path/to/baserom.jp.z64 build/rank1-reachable-search/approach-checked/2549-north-none.inputs
RANK1_SEARCH_FIRST=2549 RANK1_SEARCH_END=2969 bash instrumentation/rank1-reachable-search/capture.sh /path/to/baserom.jp.z64 build/rank1-reachable-search/box-checked/2549-box-original-90-135.inputs
```

Use the four output directories printed by those commands. The checked local
ones are shown here; fresh captures receive different names:

```powershell
& './build/wafel-pilot/python/python.exe' instrumentation/rank1-reachable-search/receipt.py --approach build/rank1-reachable-search/approach-checked --box build/rank1-reachable-search/box-checked --baseline build/wafel-pilot/capture.WlzB0D --direct build/wafel-pilot/capture.ify0TN --north build/wafel-pilot/capture.C7qKRQ --arrival build/wafel-pilot/capture.Jv3rsp --output build/rank1-reachable-search/checked-receipt.json
& './build/wafel-pilot/python/python.exe' instrumentation/rank1-reachable-search/test_check.py build/wafel-pilot/capture.WlzB0D/raw.log
```

`receipt.py` requires the full emulator controller schedules, all compared
Wafel fields under the separately checked +1 global-timer mapping, all 900
restored branch outputs and the exact checkpoint checks to agree. The baseline
also retains all three previous expected observer receipts. Six deliberately
damaged logs fail the checker; a synthetic display split is reported. Synthetic
log tests are never gameplay evidence.

`expected-receipt.json` stores compact expectations and input/log hashes.
Full controller files, states, logs, captures, libraries and ROM stay in ignored
build output. The 42,480 advances include 36,855 SSL Area-1 samples; area changes
and dead/paused intervals explain why these are different totals. Four exact
replays contain 983 first-query and 983 final-query observations. None of the
first queries fails, and every final query selects an ownerless static floor.

The supplied Ink fixture and the existing actual US/JP Clight results remain
separate evidence. This work changes no formal theorem or subjective route
estimate, and does not reconstruct startup or continue to the target stars.

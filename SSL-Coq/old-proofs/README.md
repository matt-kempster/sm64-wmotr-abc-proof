# Archived SSL proofs

These directories are old proof attempts. They are not the current SSL proof
project; the current work lives in `../less-than-one-a-press/`.

They are retained for historical context, reusable lemmas, and future
reference. Individual projects may contain incomplete, technique-specific, or
superseded arguments, so their claims and checklists must be read literally.
Nothing in this archive should be treated as establishing the current
less-than-one-A-press goal unless it has been independently promoted and
rechecked in the current project.

The archived projects are:

- `demo-warp/`
- `eyerok-manipulation/`
- `pole-bypass/`
- `ssl-parallel-universe/`
- `ssl-pyramid-item-proof/`
- `ssl-spawning-displacement-proof/`

# Arbitrary-stick analog processing

`DemoAnalogInputExecution.v` constructs a complete big-step execution of the actual generated `adjust_analog_stick` function for arbitrary signed 16-bit raw X/Y controller values. This includes the four deadzone tests, conversion to float, the real named `sqrtf` call, both branches of the magnitude cap, and the function's actual eight-byte local allocation and free. US and JP function bodies are definitionally identical; the registered boundary is `generated_demo_arbitrary_analog_call_us_jp`.

The result gives the exact symbolic float values produced by the source. Let an axis be raw-6 when raw>=8, raw+6 when raw<=-8, and zero otherwise, with the source's integer and Float32 operations. The argument to sqrtf is the Float32 sum of the two squared axes. If its returned magnitude is greater than 64, both axes are multiplied by Float32(64)/magnitude and the stored magnitude becomes 64; otherwise the uncapped axes and returned magnitude are stored. No neutral-stick restriction or artificial bound on sqrtf's returned value is assumed.

The named external contract remains a real premise: for every memory at the call, the actual `EF_external "sqrtf"` on that exact sum returns the supplied Float32 magnitude with empty trace and unchanged memory. Generic CompCert external semantics alone do not establish this contract. The proof does not assume an execution of the controller function or of an opaque analog-update helper.

The body changes only Controller bytes [4,16). The complete call preserves every typed load outside that interval in every block valid on entry, and preserves every previously valid typed access. In particular raw X/Y at [0,4), buttonDown/buttonPressed at [16,20), and separately allocated demo stream/header/current-level globals survive this callee. The calling environment must supply the actual generated structure layout, concrete sqrtf symbol/fundef resolutions, signed raw loads, and writable float destinations. The statement is a local generated-code execution theorem, not a boot-reachability result or a global no-desync theorem. The [complete post-polling caller](controller-read-execution.md) now composes this call through both iterations and the final copy, with the second logical controller absent; hardware entry and boot remain open.

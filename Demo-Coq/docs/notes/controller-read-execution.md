# Complete controller processing after polling

`DemoControllerReadExecution.v` constructs an actual `step2` execution of the original generated `read_controller_inputs` source, from its post-polling statement to `Sskip` with the original continuation. The US/JP aggregate is `generated_controller_post_polling_us_jp`. The statement assumes no execution of the controller loop. A small internal composition lemma accepts actual subtree executions, and the final theorem supplies every one from the real playback, copy, analog, disconnected-controller and player-three-copy proofs.

For every demo-record timer, arbitrary signed recorded stick bytes, arbitrary physical buttons, arbitrary prior first-controller buttons and an arbitrary record button mask, this executes the real `run_demo_inputs`, installs the first controller, performs its four input/button stores, calls the actual arbitrary-stick analog function, increments the loop index, processes the disconnected second controller, increments again, takes the actual i<2 exit test and copies the first controller's seven fields to player three. This includes timer zero EOF (neutral raw sticks and END buttons), timer one pointer advance, and other nonzero timers. The core execution needs no physical Start or prior-bit condition, so it also covers ordinary idle demo frames.

The result gives the first controller's exact raw inputs, symbolic analog floats, buttonDown and buttonPressed, and the copied player-three buttons. These values are computed from `playback_next_stick` and `playback_next_buttons`. The final demo current pointer, expected timer and original header word are retained. A read frame preserves every previously loaded cell avoiding the current-pointer cell, output pad, timer byte and Controller bytes [0,76); this includes a separately allocated current-level global when its disjointness is supplied.

Start and EOF guards are separate corollaries of that proved final buttonPressed load. With a nonzero timer, physical Start pressed and previous Start clear, `controller_final_pressed_new_start_guards` proves the actual Start test true and END test clear. With timer zero and previous END clear, `controller_final_pressed_eof_guards` proves the actual END test true and Start test clear. The core execution itself remains valid when those bit conditions do not hold.

The concrete premises include `ge = Clight.globalenv prog` through the program parameter, actual generated structure offsets and function-symbol/fundef resolutions, first controller pad offset zero, disconnected second controller, actual P1/P3 pointers to controller offsets 0/56, separately allocated stream/current/pad/global pointer cells, a stream record at offset at least four, the actual record/header/button loads, writable playback destinations, and a writable 84-byte three-controller region. Analog processing uses the explicit pure `EF_external "sqrtf"` contract on the exact Float32 squared-axis sum of the emitted sticks, including its supplied return value. No neutral-stick, positive-timer or new-Start restriction is imposed.

The entry is after the function's hardware-polling prefix. This theorem does not establish SDK polling contracts, boot reachability of these premises, the connected second-controller path, stream-region/record-bound induction, the subsequent complete normal frame, whole-game exclusion of alternate level changes, or a global no-desync result. The gameplay verdict remains open.

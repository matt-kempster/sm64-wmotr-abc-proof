What "the end" means here

Finish line: one theorem a reader can check by reading it, saying that from any state the real game can be in when WMotR starts, a run with no A press never collects the red-coin star. Its trust ledger (docs/TRUST.md) shrinks to the Coq/CompCert foundations plus C-versus-N64 items that are checked against the real game. Some rows can never become proofs, such as thread concurrency and trusting clightgen, so "done" means tethered, not zero.

Not counted: proving the matching ROM equals the C, and alternative routes like other red coins. Coin #2 alone is enough for the argument.

How the numbers move: a discharged row moves effort from orange to blue. A found falsehood can move the total down, which is still progress. The whiskers should narrow as gaps get scoped.

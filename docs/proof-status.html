Super Mario 64 · A-Button-Challenge impossibility · Rocq + CompCert

Can “Wing Mario over the Rainbow” be beaten without pressing A?

The project aims at a machine-checked no: a Coq theorem, grounded in the mechanically-translated (clightgen) C of the actual game, that WMotR’s star is unreachable under never-press-A inputs. It splits into two goals.

GOAL 1 · COMPLETE no-A ⇒ Mario never enters a flying action GOAL 2 · ACTIVE without flying, Mario’s height stays below the star Last updated 2026-07-10

Rule “PIPELINE, not bespoke”: no hand-written model of the game is ever trusted. Every offset, constant, and function body cited in a proof is read off the generated AST.

GOAL 1 — no-A ⇒ no-fly proved

Six audited theorems, all passing the discipline audit (build · no admits · standard CompCert axioms only · firewall clean). The sharpest form:

noA_no_spawn_never_flying_linked12

For any CompCert link of the twelve clightgen’d action TUs: a run that starts in a well-formed WMotR spawn state, under inputs that never press A and never spawn flying, never reaches a flying action. Companion theorems linked12_inhabited (the twelve TUs provably link — zero hypotheses) and linked12_init_mem (its initial memory exists) make the quantification non-vacuous.

The antecedent is not a hypothesis row

mem_ok_lp init — “the run starts in a well-formed WMotR spawn state” — is the theorem’s conditional. Discharging it would mean modeling boot + level-load outside the twelve TUs (inventing the initial state). The honest form is the conditional we have.

History worth remembering: four hypothesis rows that looked fine were found false of the real game (vacuous capstone, bully aliasing, sound-flag OR, dead return-plumbing) and repaired — green-and-axiom-clean never means non-vacuous. The store-scout audit (classify every store against the generated AST) is the only method that caught them.

GOAL 2 — WMotR requires A active

Remaining gap: even without flying, could no-A Mario climb to the star some other way? The target invariant is a height bound: m→pos[1] ≤ H* for every reachable frame, with the star’s grab window above H* (real moat ≈ 622 units, margin ≈ 349 after the pole-grab correction). Reading the colors

  • proved — a Qed’d theorem on the spine, standard axioms only.
  • assumed — dischargeable — a named hypothesis with a concrete discharge plan; the working scoreboard.
  • honest boundary — assumed by design: facts outside the verified TUs (object pool, run layout, CompCert’s external-call model). These are what the final theorem will ask a reader to accept.
  • active front — where current work is aimed.

# SSL Parallel Universe proof

This project studies, against CompCert Clight generated by `clightgen`, whether
Mario can enter a parallel universe during SSL Area 2 play. The bounded normal
step is proved unable to do so, but the wider claim is false in the current
source-shaped model: the project contains a concrete vertical-Grindel BLJ
counterexample certificate.

The durable recovery copy of the objective and result is tracked in
`docs/goal.md`.

This directory is self-contained. The existing
`SSL-Cog/ssl-pyramid-item-proof/` project is used only as a structural and style
reference.

## Proof route

```text
US SM64 source and SSL collision literals
  -> CompCert clightgen
  -> committed generated Clight ASTs
  -> source-shape and arithmetic lemmas
  -> dynamic Grindel collision certificate
  -> concrete Area 2 PU counterexample
```

Generated Clight files are never hand-edited.

## Current result

`proofs/BLJDynamic.v` proves
`ssl_area2_grindel_dynamic_counterexample_certificate`. The finite certificate
starts with a bounded normal long jump on the Area 2 vertical Grindel, uses its
10-unit rise for nine in-footprint BLJ recycles, establishes a static-floor
release anchor, and reaches a distant X coordinate whose signed-16 alias has a
concrete Area 2 floor.

The capstone composes generated Clight AST checks with exact rational route
arithmetic and an independently checked collision-mesh certificate. The exact
scope and remaining optional semantic lowering are documented in
`docs/claim.md` and `docs/checklist.md`.

## Build

Use the same Rocq/Coq and CompCert environment as the sibling SSL proof:

```sh
source pipeline/env.sh
make generated
make proofs
bash pipeline/check.sh
```

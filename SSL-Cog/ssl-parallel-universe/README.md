# SSL Parallel Universe proof

This project studies, against CompCert Clight generated by `clightgen`, whether
Mario can enter a parallel universe during SSL Area 2 play. The unrestricted
claim is false: the project contains a concrete vertical-Grindel BLJ
counterexample certificate. The stricter no-new-A claim is proved impossible
under the project's source/mesh execution certificate, even when
`INPUT_A_DOWN` varies while `INPUT_A_PRESSED` remains clear.

The durable recovery copy of the objective and result is tracked in
`docs/goal.md`.

This directory is self-contained. The sibling SSL Pyramid proof is used only
as a structural and style reference.

## Proof route

```text
US SM64 source and SSL collision literals
  -> CompCert clightgen
  -> committed generated Clight ASTs
  -> source-shape and arithmetic lemmas
  -> unrestricted dynamic Grindel PU counterexample
  -> no-new-A source/mesh invariant
```

Generated Clight files are never hand-edited.

## Current result

`proofs/BLJDynamic.v` proves
`ssl_area2_grindel_dynamic_counterexample_certificate`. The finite certificate
starts with a bounded normal long jump on the Area 2 vertical Grindel, uses its
10-unit rise for nine in-footprint BLJ recycles, establishes a static-floor
release anchor, and reaches a distant X coordinate whose signed-16 alias has a
concrete Area 2 floor.

`proofs/NoAPressed.v` separately proves
`ssl_area2_no_new_a_parallel_universe_certificate`. Area entry resets Mario's
speed; fresh A presses are required for the BLJ multiplier; all 32
very-slippery triangles form nine finite charging components; and the
conservative no-A quarter-step bound is `256`, below the `54630`-unit gap to
the first reusable static-floor alias. The theorem accepts any per-frame
A-down schedule.

Both capstones compose generated Clight AST checks with exact arithmetic and
independently checked source/collision literals. Their exact scope and the
optional full-semantics lowering are documented in `docs/claim.md` and
`docs/checklist.md`.

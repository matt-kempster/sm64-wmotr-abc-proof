# SSL Parallel Universe proof

This project aims to prove, against CompCert Clight generated by
`clightgen`, that Mario cannot enter a parallel universe during normal SSL
area 2 play under the modeled area-2 bounds. If the claim is false, this
directory should instead grow a concrete counterexample.

The durable recovery copy of the active proof objective is tracked in
`docs/goal.md`.

This directory is intentionally self-contained. Build and proof files live
under `SSL-Cog/ssl-parallel-universe/`, while the existing
`SSL-Cog/ssl-pyramid-item-proof/` project is used only as a style reference.

## Intended route

```text
source C model
  -> CompCert clightgen
  -> committed generated Clight AST
  -> Rocq lemmas over the generated program shape and arithmetic model
  -> auditable no-PU capstone theorem
```

Generated Clight files are never hand-edited; regenerate them from `inputs/`
with `make generated` once `clightgen` is on `PATH`.

## Build

Use the same Rocq/Coq and CompCert environment as the SSL Pyramid proof:

```sh
source pipeline/env.sh
make generated
make proofs
bash pipeline/check.sh
```

The current proof target and open obligations are tracked in `docs/claim.md`
and `docs/checklist.md`.

# SSL-Cog

welcome to the SSL 0A rabbit hole.

This folder is for the big Shifting Sand Land question: can we collect
**Inside the Ancient Pyramid** and **Pyramid Puzzle** with 0 A presses?

The working answer is "probably no", but the actual job here is stronger than
vibes. We either prove the no, or we find the counterexample and everyone has
to update their mental model. Either outcome is useful, as long as it is backed
by real source/proof work and not just "trust me bro".

## Why these three folders are together

These are the main escape hatches people keep having to think about:

- `ssl-parallel-universe/` asks whether the pyramid-interior movement can get
  Mario into PU nonsense that breaks the usual reachability story.
- `ssl-spawning-displacement-proof/` checks the JP spawning-displacement /
  stale-platform idea, especially the Spindel route everyone naturally side-eyes.
- `ssl-pyramid-item-proof/` checks whether some outside object/item/reference
  can survive the area change into the pyramid in a way that still matters.

So yeah, the folder name is basically "all the SSL cog-turning that supports
the 0A star disproof". If one of these finds a real route instead, awesome:
that is exactly the kind of receipts this folder is here to preserve.

## How to read this

Start with the README in whichever subfolder matches the trick you care about.
Each project is intentionally self-contained: it has its own `Makefile`,
`pipeline/`, `generated/`, `proofs/`, and notes. The top-level idea is shared,
but the proof stacks are separate because each route hypothesis attacks the
problem from a different angle.

Do not treat old TODOs or half-lowered claims as final results. The useful
stuff is the named theorem/checklist status in each project README and docs.
If a claim is conditional, it is conditional. No victory laps off a condition
that still contains the actual hard part.
